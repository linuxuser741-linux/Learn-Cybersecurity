• Linux Fundamentals

Whether you are a beginner or an experienced cybersecurity professional, using a Linux distribution is highly recommended. If you are still using Windows for this field, I suggest switching to any Linux distribution you prefer. Some of the most popular Linux distributions include Ubuntu, Fedora, Debian, and Kali Linux. Today, we are learning the basics of the system, including commands for controlling the system through the terminal.

The first command we have today is :

• ls

This command is used to display folders and files of the system that your current user can access according to your permissions.
